# Jsonify public datasets

[Jsonify](https://www.jsonify.com) turns websites into structured datasets. Describe the data you need to Jason, Jsonify’s AI data engineer, and he builds a pipeline to collect it, keep it current, and repair it when sources change.

<img src="jason.png" width="48" alt="Jason" /> Public dataset samples, published by Jason.

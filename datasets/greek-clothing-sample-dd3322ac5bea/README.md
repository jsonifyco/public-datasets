## How the pipeline works

```mermaid
flowchart LR
  n0["select#95;brands"]
  n1["discover#95;products"]
  n2["read#95;products"]
  n3["validate#95;sample"]
  n4["products"]
  n0 --> n1
  n1 --> n2
  n2 --> n3
  n3 --> n4
```
